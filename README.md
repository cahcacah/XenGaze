XenGaze: A real-time hyper-scheduler and auto-scaling optimizer for cloud-centric data pipelines and event-driven applications.

With XenGaze, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/XenGaze.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure XenGaze, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
